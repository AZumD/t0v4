# TOVA v4

Dual-brain AI companion system (Mixtral + Phi) with orchestration, memory, RAG, plugins, and a minimal frontend.

- Backend: FastAPI
- Realtime: WebSocket
- Memory: ChromaDB + Redis placeholders
- Config: YAML-driven personalities, moods, and functions

Directory structure focuses on maintainability and separation of concerns.

See `docs/README/OVERVIEW.md` for a component map.
